# Security policy

## Reporting a vulnerability

Do not open public GitHub issues for credential-handling, replay-safety, SSH, or transport-security vulnerabilities.

Report vulnerabilities privately to the maintainers through GitHub Security Advisories or by contacting the repository owners listed in the GitHub repository settings.

## Scope

Security-sensitive areas include:

- Redis and SSH credential storage
- SSH host-key verification
- Replay and export workflows
- Webview message validation and CSP
- Workspace-trust behavior

## Supported versions

Only the latest released version is supported with security fixes.
